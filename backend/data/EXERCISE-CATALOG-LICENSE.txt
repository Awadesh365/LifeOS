LifeOS public exercise reference catalog

Source: https://github.com/rthepen/workout-database
Upstream distribution: https://github.com/rthepen/workout-database/blob/main/dist/all_exercises.json
License: MIT
Snapshot retrieved: 2026-10-17

The bundled public-exercise-catalog.json is an upstream snapshot and includes exercise
names, instructions, muscle/equipment metadata, and selected video references. Imported
database rows retain the source URL and MIT license label. LifeOS-authored exercise
entries remain separate from this public dataset.
