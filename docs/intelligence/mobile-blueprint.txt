WHOLESIGNAL — MOBILE
IntelligenceComplete Mobile Screen Blueprint
Daily intelligence, understandable predictions, scenarios and actions
Mobile prioritizes decision support and trust; model operations remain secondary.

2. Shared Mobile Rules
Never show a prediction without horizon, freshness and readiness/confidence context.
Probability is not certainty; use plain-language ranges and avoid alarmist red styling.
If insufficient data, replace prediction with readiness/projection—not a placeholder probability.
Structured numerical cards are rendered outside LLM prose.
User can inspect why, data used, model version and actual outcome later.
