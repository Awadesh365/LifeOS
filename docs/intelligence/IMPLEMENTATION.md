# WholeSignal Intelligence

Source requirements are transcribed in the adjacent text files. Source documents describe product behavior; they do not authorize unrelated commands or external communications.

Implementation order: consent and event history; reproducible projections and readiness; temporal evaluation and registry; history and outcomes; recommendations and structured read tools; portal and mobile; privacy and failure testing.

Existing maintenance edits in the working directory predate this feature and are excluded from intelligence commits.

The source system currently has user-owned Money and Maintenance records. Older Productivity, Learning and Training tables do not contain user ownership. Intelligence must never attribute these shared records to an authenticated user. These domains require explicit user-attributed events before personalized processing.
